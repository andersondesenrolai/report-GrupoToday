# Relatório CRM — Grupo Today · Agosto 2026

Apresentação estática de fechamento para Réveillon Saudade, Mundo Psicodélico e TodayLand.

## Publicação

O projeto não requer etapa de build. Na importação pelo Vercel, mantenha:

- Framework Preset: `Other`
- Build Command: vazio
- Output Directory: vazio

O Vercel servirá o arquivo `index.html` e a pasta `assets/` diretamente.

## Arquivos principais

- `index.html`: apresentação navegável.
- `Relatorio CRM - Agosto 2026.pdf`: versão para envio ao cliente.
- `assets/`: fontes, logo e imagens usadas na apresentação.

## Nota metodológica

Custos convertidos com PTAX média de agosto de 2026 (R$ 5,1511 por US$ 1). O ROAS do Réveillon Saudade compara receita rastreada pelos cupons CRM01–03 com o custo CRM convertido; não inclui margem, taxas ou receita Injoy.
